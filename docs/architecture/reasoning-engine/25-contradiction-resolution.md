# 25 — Contradiction Resolution

## Purpose

This document defines analytical treatment of contradictions. “Resolution” means classifying or explaining a conflict when explicit evidence permits; it never means deleting evidence or exercising normative authority.

## Resolution Classes

- **Context-Separated:** claims apply to different explicit Scopes.
- **Time-Separated:** claims apply to different effective intervals or versions.
- **Terminology-Separated:** apparent conflict follows from proven definition differences.
- **Authority-Preceded:** an explicit canonical precedence rule applies within Scope.
- **Reconciled by Evidence:** additional package evidence shows compatible interpretation.
- **Unresolved:** evidence cannot safely distinguish.
- **Normative Review Required:** authority must decide.

## Preservation

All original claims, sources, citation anchors, authority, versions, classifications, and conflict records remain visible after analytical resolution. A resolved classification never modifies Phase 13's Conflict Set.

## Rules

- **CONTRADICT-001:** Reasoning must never silently discard, merge, average, or rewrite contradictory evidence.
- **CONTRADICT-002:** Analytical resolution requires explicit evidence or an applicable canonical rule.
- **CONTRADICT-003:** Authority precedence must not be invented or generalized beyond Scope.
- **CONTRADICT-004:** Unresolved and normative conflicts must remain visible in Results and Output Package.
- **CONTRADICT-005:** A resolution classification must preserve every original conflict artifact.
- **CONTRADICT-006:** Reasoning must not decide which source is true absent deterministic canonical authority.

## Enterprise Example

Two statements conflict until version intervals show they governed different releases. Reasoning may classify the conflict as time-separated while retaining both original statements and their Phase 13 conflict record.

## Boundaries

No source correction, canonical arbitration, policy decision, approval, or Conflict Set mutation is authorized.

# 05 — Option Generation

*The stage after Constraint Analysis.*

## What it means

Option Generation is where reasoning **produces the candidate courses of action**. Within the goal and inside the constraints, the engine generates the distinct, viable options worth considering — the real alternatives among which a decision could be made. This is the divergent stage: reasoning widens before it narrows.

Options are candidates, not decisions. Each is a genuinely available way to pursue the goal, respecting the constraints. Generating them is reasoning exploring the field; choosing among them comes later.

## Why it exists

Because a decision is only as good as the set of options it chooses from. If reasoning surfaces a single option, it has pre-decided — and the Director's choice is an illusion. Option Generation exists to ensure a **real field of alternatives**, so that trade-off analysis has something to weigh and the Director has a genuine choice. It embodies the honesty of the Phase 7A principles: no option is hidden to make a favored one look inevitable ([first principles](../director-reasoning/02-first-principles.md)).

## Required inputs

- **Identified goals** — what the options must serve.
- **Constraint set** — the boundaries every option must respect.
- **Contextualized understanding** — so options fit the actual situation.

## Expected outputs

- **Option set** — a spread of distinct, viable candidate actions, each respecting the constraints and pursuing the goal.
- For each option, its **committing status** — whether it stays on the free side of the Director Gate or would require explicit approval to enact ([constraint analysis](04-constraint-analysis.md)).
- Explicit inclusion of the **status-quo / do-nothing** option where relevant — not acting is always a real alternative.

## Transition criteria

Reasoning may move to Trade-off Analysis when:

- more than one genuine, constraint-respecting option exists (or it is honestly established that only one viable path exists);
- each option is distinct and actually available, not a straw alternative;
- the do-nothing option has been considered.

If reasoning has only one option because it stopped looking, it stays here. A single un-weighed option is a pre-decision, not a recommendation.

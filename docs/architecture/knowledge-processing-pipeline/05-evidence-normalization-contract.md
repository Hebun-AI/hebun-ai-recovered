# 05 — Evidence Normalization Contract

## Definition

**Evidence Normalization** creates a comparable view of qualified evidence while preserving original meaning, wording, authority, provenance, lifecycle, version, scope, and material variance.

Normalization reduces representational difference. It does not interpret, summarize away exceptions, reconcile conflict, or rewrite canonical sources.

## Normalization Concerns

Permitted concerns include:

- stable reference form;
- terminology alias resolution against canonical identity;
- lifecycle and version presentation;
- temporal representation;
- scope qualification;
- authority-class presentation;
- relationship-direction presentation;
- source-location representation;
- explicit treatment of missing values;
- comparable formatting of equivalent evidence.

## Normalization Record

Every material normalization records:

- source evidence identity;
- original representation;
- normalized representation;
- concern addressed;
- applied canonical reference;
- equivalence status;
- preserved variance;
- rationale;
- reviewer or governing authority when required;
- confidence and uncertainty;
- validation result.

## Equivalence Status

| Status | Meaning |
|---|---|
| **Equivalent** | Normalized form preserves the same meaning within resolved scope |
| **Equivalent with Variance** | Core identity aligns but material wording, scope, version, or exception differs |
| **Not Equivalent** | Evidence represents different meaning or identity |
| **Ambiguous** | Available evidence cannot establish equivalence |
| **Conflicted** | Applicable sources assert incompatible equivalence or identity |

No status authorizes canonical terminology change.

## Source Preservation

The original source remains directly accessible by reference from every normalized item. A consumer must be able to distinguish source wording from normalized representation.

## Semantic Variance

Variance includes:

- narrower or broader scope;
- lifecycle difference;
- version difference;
- authority difference;
- exception or condition;
- relationship direction;
- temporal applicability;
- translation or terminology nuance.

Material variance cannot be removed for convenience.

## Required Distinctions

- Normalization ≠ Interpretation
- Equivalence ≠ Identity Creation
- Alias Resolution ≠ Canonical Rename
- Comparable Form ≠ Equal Authority
- Missing Value ≠ Default Value
- Normalized Evidence ≠ Canonical Source

## Enterprise Example

Two documents use different labels for one canonical Concept, but one applies only to an archived version. Normalization links both labels to the Concept while preserving lifecycle variance. It does not present the archived statement as current.

## Boundaries

No parser, transformation algorithm, language model, translation service, mapping implementation, schema, or storage is selected.

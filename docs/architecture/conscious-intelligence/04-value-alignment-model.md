# 04 — Value Alignment Model

## Definition

Value Alignment helps users compare current actions, commitments, and trajectories with values they have explicitly defined or approved. It offers observations and reflection; it does not judge character, impose morality, or choose for the user.

## Value Domains

Possible user-selected domains include family, faith, education, health, leadership, business, ethics, financial responsibility, creativity, service, and personal growth. The list is extensible only by the user or authorized governance.

## Model

A Value Alignment Assessment contains:

- user-approved value statement;
- scope and effective period;
- relevant actions or commitments;
- supporting and contradicting evidence;
- alignment, tension, unknown, or not-applicable finding;
- confidence and uncertainty;
- trade-offs and competing values;
- reflection questions;
- user annotation and decision.

## Allowed Capabilities

- detect evidence of alignment or tension;
- identify competing commitments;
- explain why an observation was made;
- compare current and historical user-approved value statements;
- surface missing evidence;
- offer neutral reflection questions.

## Prohibited Capabilities

- assigning values to a user without approval;
- rating moral worth;
- using shame, fear, guilt, praise dependency, or social pressure;
- treating inconsistency as hypocrisy or diagnosis;
- overriding a user decision;
- optimizing engagement through value conflict;
- privileging the system's values over the user's lawful choices.

## Enterprise Example

A founder has approved “family presence” and “sustainable leadership” as values while repeatedly scheduling avoidable late meetings. The system may show the pattern, evidence, exceptions, and uncertainty, then ask whether the schedule still reflects current priorities. It must not accuse or command.

## Boundaries

Value alignment ≠ moral judgment, observation ≠ diagnosis, conflict ≠ failure, and recommendation ≠ obligation.

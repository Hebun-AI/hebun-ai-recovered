# Phase 17 — Director & Architecture Agents

## Purpose

Phase 17 defines the constitutional foundation under which agents may participate in Hebun AI. It introduces bounded Director-facing and architecture-specialist participation without transferring authority, ownership, decision, approval, authorization, execution, Runtime, or organizational responsibility to an Agent.

Phase 17 defines no business-domain Agent, communication architecture, delegation protocol, shared memory, workflow, orchestration engine, Runtime behavior, or implementation.

## Canonical Position

```text
Phase 1–16 — canonical enterprise and intelligence foundations
        ↓
Architecture Intelligence Completion Amendment
        ↓
Phase 17 — constitutional Agent participation
        ↓
Phase 18+ — future governed Agent specializations and coordination
```

This is dependency layering, not a workflow or execution sequence.

## Constitutional Invariants

- Director = Final Authority
- Agents = Specialized Participants
- Runtime = Execution Layer
- Agent ≠ Director
- Agent ≠ Authority
- Agent ≠ Execution
- Agent ≠ Runtime
- Agent ≠ Organization Owner
- Reasoning ≠ Decision
- Governance ≠ Decision
- Decision Support ≠ Approval

# G7.1 — Focused Heby Mode — closure

**Released at tag `hebun-g7-1-focused-heby-mode`. Classification C — presentation architecture.**

---

## The claim

On `/heby`, at `lg` and above, Heby's own surface is the product: the shell's workspace navigation
stands down, the remaining chrome recedes into the field, and the presence is bounded by the room it
actually has on both axes. The composition is the approved reference's — a luminous origin low in
the frame, ascending points, a particle landscape, a translucent decision column — built entirely
from static layers.

## What this is NOT a claim of

- Not a new capability. Nothing here reads, writes, decides or reaches a model.
- Not a claim that Heby knows anything about the operator. The interaction node states a released
  UI rule and nothing else.
- Not a claim that the organization is doing anything. Every decorative layer is a function of no
  value; the only surface that changes with real state is the presence field, and each of its states
  is also stated in words.
- Not a change to the operator's own navigation preference, which is read, temporarily overridden in
  width, and left exactly as found.

## The four things this phase learned the hard way

1. **A preference can be lost by not being applied.** Unmounting the control that writes a stored
   preference also unmounts the effect that applies it. The stored value stayed correct while the
   product contradicted it.
2. **A build pipeline can delete a declaration and leave every test green.** A custom property whose
   value is a `min()` of mixed absolute and container units is dropped silently. The presence fell
   back to a smaller step in the real product; only measuring the authenticated page found it.
3. **Ink is overflow.** A glow that bleeds past its box is counted as scrollable content. Clipping it
   draws a rectangle; reserving it costs layout. The reserve has to scale with the thing that bleeds.
4. **A composite mask is not a mask.** Two intersected mask layers rendered as a hard-edged bright
   rectangle in the real product. One ellipse cannot come apart.

## Subtractions, by direction

- The reference's concentric arcs: built, then removed — behind the presence they read as a radar
  sweep, and Heby has nothing to sweep. The presence's own orbital traces are untouched.
- The three example prompt chips in the Full Workspace: removed, with nothing put in their place.
  The composer is unchanged and the Quick Panel still offers them.

Both removals are held by inverted assertions rather than by deleted ones, so neither can drift back
in unnoticed.

## Reversal recorded

The previous pass made the Akışı rail's DEFAULT adaptive — collapsed on an empty or failed read.
This release returns the default to open, because the reference composition needs the column
present, and carries the read's truth entirely in the rail's content instead. That is a different
claim, not a stronger one, and the test says so in words. The empty/unavailable distinction still
survives collapsing.
